# FLASHY BIRD 🐦🌀

Flappy bird — but seen from behind, flying through a flashy hypnotic space tunnel that revolves randomly.

**Play it:** https://nusability.github.io/flashybird2/

Tap / click / Space to flap. Fly through the glowing gate holes, dodge the sweeper arms and
asteroid slaloms, grab power-ups, catch glowbugs, and spend them in THE NEST.

Every day is a new deterministic tunnel — the same course for everyone. `?seed=anything` picks
a custom one.

Fly a zone map of themed worlds — each zone is seven levels, with its own palette, wildlife and
weather — or take a run at the daily tunnel from the title screen.

Zero dependencies. The game is [`index.html`](index.html) plus the theme packs in
[`themes/`](themes); [`classic.html`](classic.html) is the original single-tunnel game, kept as
it was, and `zones.html` is a redirect for home-screen apps installed before the game moved to
the root.
